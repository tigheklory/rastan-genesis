Phase-1 → Phase-2 transition — MECHANISM PROVEN (control flow)

The mid-round phase transition is data-driven by a map-collision tile, not a scene table and not the background bank. The player↔map probe (player_ground_contact_probe_family_53b34 + horizontal probe 0x53e22–0x54050) reads the collision grid at 0x10DE00 (= A5+0x1E00) via 0x53a2e; tile type = cell & 0x7F. Tile type 0x7E (126) = the door → A5+0x10E8 := 7 (0x53f0c, 0x54038); type 8 → 0x10E8:=8. Consumed at 0x3a7d2 (saves 0x1242:=0x13E, state 2, 0x0104:=1) → screen-wipe (0x1394/0x13aa/0x138a) + actor-clear (0x3a804) + scene reload + 0x13E restore. Round-complete is distinct: 0x10E8:=16 (0x51250) at a 0x502AC boundary.
A5 = 0x10C000 (arcade base) — verified this pass. Hence 0x10D000 = A5+0x1000 (16 map-column stream ptrs, 0x502cc) and 0x10D0A8 = A5+0x10A8 = the section-kind, which is set from the map-stream byte at ROM 0x50F6B (indexed by 0x13E via 0x50EE0). That stream holds only (0, 1, 2), so the director's A5+0x10A8∈{4,5,6} path (0x527cc) is DEAD CODE — the 0x7E tile is the sole live wipe trigger.
Exact blocker (not fabricated): no code writes 0x7E into the collision grid, so it is a metatile-property value in the map data. Enumerating per-round door 0x13E needs the metatile→collision-property mapping + the per-round metatile-column source feeding collision-grid field @(20) — a full map-engine decode. Boundary pinned: 0/6 (mechanism proven; positions blocked). No screenshot or TT-bank appearance is used as the phase authority.

Background-bank (TT) map — SUPPORTING evidence only (not the phase-defining field)

0x13E → 0x507C5 → scene index → 12-byte descriptor 0x3951C; the TT byte is the background-tileset bank (streamed at 0x55c7a). Mid-round bank change PROVEN only in R3 (@0x36), R5 (@0x6C, @0x72), R6 (@0x83, @0x89); R1/R2/R4 stream one bank — which is exactly why a bank change cannot define the gameplay phase (R1/R2/R4 cross the phase within one bank). TT0E(R5)/TT0F(R6) are boss-arena banks. Detail: Andy_outdoor_castle_section_map.md, Andy_scene_phase_state_machine.md.
