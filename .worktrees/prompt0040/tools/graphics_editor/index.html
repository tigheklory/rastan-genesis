How to use
  1. Create editable profile (baseline is read-only).
  2. Pick an Object on the left → the center shows the Source Colors it actually uses.
  3. Click a Source Color. Click a second source color to Compare (ΔE00), or…
  4. Click a Genesis Target entry (top-right grid) → Map source here.
  5. Adjust the legal Genesis color with the R/G/B level sliders.
  6. Map colors from other objects to the same target entry to share (cross-object).
  7. Compare Arcade vs Genesis in the previews. Resolve warnings. Save.
PROVEN=full arcade evidence · PARTIAL/UNKNOWN=incomplete (shown honestly) · MRD "Must Stay Distinct"=two colors used inside one sprite may never merge · Exact match=identical palette content (lossless) · Natural Genesis=quantized target color · Target line/entry=one of 4 CRAM lines × 16 · Profile=a saved set of your choices.
