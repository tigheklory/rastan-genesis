# Cody — Build 0452 BEST-5 Runtime Address-Arithmetic Elimination

## Result

Build 0452 is a bounded durability/performance cleanup on accepted Build 0451. It preserves the shared native HUD architecture and all live BEST-5 values while moving numeric descriptor source conversion from runtime to build time.

The original arcade numeric table at arcade PC `0x03C37C` contains thirteen 10-byte records: `count.w, destination.l, absolute WORKRAM source.l`. The generator now validates each source against the positive signed-word domain rooted at arcade A5 base `0x0010C000`, computes `source - 0x0010C000`, and emits thirteen 8-byte records: `count.w, destination.l, A5 displacement.w`. The generated range is `0x0013–0x0156`.

The original NAME table at arcade PC `0x03C454` already contains eight 6-byte records whose source field is an A5-relative word. The generator preserves that distinct record shape, validates each source as a positive signed-word A5 displacement, and proves the adjacent NAME range `0x0157–0x0168`.

At runtime:

- `genesistan_hook_number_renderer_3c2e2` indexes 8-byte records and uses `movea.l a5,a4; adda.w 6(a0),a4`;
- `genesistan_hook_highscore_fg_producer` uses `movea.l a5,a2; adda.w 4(a0),a2`;
- no `source - 0x0010C000`, Genesis WRAM-base addition, arcade-to-Genesis source conversion, ROM relocation calculation, or manually maintained `0x00FFxxxx` source remains;
- both generated ROM tables are referenced through linker symbols.

SCORE, ROUND, and NAME continue to read live arcade-owned state. No ranking WRAM is seeded and no factory ranking is compiled into production. Numeric leading-zero suppression remains `cmpi.w #6,(a0)`.

## Semantic boundary and architecture

The bounded semantic path is:

`original arcade BEST-5 descriptor authority -> build-generated native descriptor -> live A5-relative ranking state -> retained native Plane-A producer`

This task does not change a PC080SN/PC090OJ semantic cut or retire another chip tail. The already-native Plane-A producers and the Build-0451 shared HUD/title architecture remain intact. The only legacy dependency removed is runtime conversion of an absolute arcade WORKRAM source representation.

Legacy intentionally remaining: the original arcade descriptor tables remain in the relocated maincpu image as provenance/authority; the established numeric and NAME semantic producers remain responsible for live value formatting and Plane-A output.

## Static proof

The strengthened `verify_best5_native_tables.py` independently decodes original `maincpu.bin`, proves every numeric output equals `original_source - 0x0010C000`, validates all numeric and NAME offsets fit positive signed `ADDA.W`, verifies the unchanged original tables at address-map locations `0x03C560` and `0x03C638`, and verifies the generated bytes in the final ROM at linker symbols:

- `genesistan_number_descriptor_table = 0x075760`;
- `genesistan_highscore_name_descriptor_table = 0x0757C8`.

Final linked code disassembly proves direct symbol references and the two A5-relative effective-address operations. The verifier also rejects stale `0x03C57C`/`0x03C654` literals, runtime source-base conversion, magic WRAM source bases, loss of leading-zero semantics, and factory ranking literals in production source.
